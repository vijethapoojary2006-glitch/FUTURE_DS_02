# Customer Retention & Churn Analysis

About
This project analyzes customer data from a subscription-based business to identify churn patterns, retention trends, and key factors affecting customer lifetime value.

Objective
- Identify customer churn patterns
- Analyze retention trends
- Find common reasons for customer churn
- Analyze customer lifetime value (LTV)
- Provide recommendations to improve customer retention

Tools Used
- Python
- Excel
- Power BI

Key Analysis
- Churn Rate
- Customer Retention
- Churn Reasons
- Churn by Subscription Plan
- Customer Lifetime Value
- Customer Engagement
- Customer Satisfaction

Files
- `Customer_Churn_Sample_Dataset.pdf` – Sample customer dataset
- `task2_dashboard_overview.png` – Churn overview dashboard
- `task2_dashboard_retention.png` – Retention analysis dashboard
- `task2_dashboard_insights.png` – Actionable insights dashboard

Recommendations
- Improve customer onboarding and engagement.
- Contact customers with low satisfaction scores.
- Resolve repeated support issues quickly.
- Send payment-failure reminders.
- Provide suitable retention offers before subscription renewal.

Note
The dataset used in this project is synthetic and created for internship/portfolio practice. It does not contain real customer information.
